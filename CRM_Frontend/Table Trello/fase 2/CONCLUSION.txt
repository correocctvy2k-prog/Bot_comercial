🚀 CÓMO EMPEZAR AHORA

1. Descargar todos los archivos de tu carpeta Descargas

2. Instalar dependencias backend:
   cd backend
   npm install openpyxl

3. Verificar acceso a Excel:
   \\ganepalmir\dpto.informatica\...\2026 programacion anual CCTV.xlsx

4. Ejecutar en 2 terminales:
   Terminal 1: cd backend && npm run dev
   Terminal 2: cd frontend && npm run dev

5. Acceder a http://localhost:5173

6. Registrar webhook de Trello (optional, pero recomendado para sync automático)

7. Probar: Marca un checklist en Trello → Dashboard se actualiza + Excel marcado

📝 NOTAS IMPORTANTES

1. Nombres de puntos:
   - Deben ser EXACTOS entre Trello y Excel
   - Mayúsculas, espacios, tildes: TODO importa

2. Archivo Excel:
   - NO puede estar abierto mientras se sincroniza
   - Backend lo abre/cierra automáticamente
   - Ruta UNC debe estar accesible

3. Períodos:
   - R1: Enero, Febrero, Marzo, Abril
   - R2: Mayo, Junio, Julio, Agosto
   - R3: Septiembre, Octubre, Noviembre, Diciembre

4. Zonas:
   - PALMIRA, AMAIME, CANDELARIA, PRADERA, FLORIDA, ROZO, OCCIDENTE
   - Se detectan automáticamente del nombre del punto
